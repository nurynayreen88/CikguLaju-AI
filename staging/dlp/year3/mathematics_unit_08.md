# Mathematics (DLP) · Year 3 SK · Unit 8 Location

## DLP-MAT-Y3-U08-67 · Describe position from a reference point

**Standards** · CS 8.1 · LS 8.1.1
**References** · Textbook Part 2 pp. 97–99 · Activity Book pp. 139–140
**Learning objective** · Locate three items using directional words and a named reference point.
**Materials** · A tabletop classroom map, object cards and arrow labels.

| Phase | Teacher | Pupils |
| --- | --- | --- |
| Set induction · 5 min | Place a library card at the centre and a garden card to its right. | Describe the garden's location using the library as reference. |
| Main activity · 30 min | Fix the map's orientation and model statements for left, right, in front of and behind. Change the reference point to show how the statement changes. | Move object cards into position and describe them to a partner using a named starting point. |
| Practice and assessment · 20 min | On a map with the hall at the centre, place the library left of the hall, the office right and the garden in front. Check three location statements relative to the hall. | Write where each object is using the hall as the reference point. |
| Closure · 5 min | Ask where the hall lies from the library. | Reverse the reference and say the hall is to its right. |

## DLP-MAT-Y3-U08-68 · Name and locate objects on a grid

**Standards** · CS 8.1 · LS 8.1.2, 8.1.3
**References** · Textbook Part 2 pp. 99–102 · Activity Book pp. 140–142
**Learning objective** · Name the object at a given position and record locations using horizontal then vertical values.
**Materials** · First-quadrant grids, counters and landmark stickers.

| Phase | Teacher | Pupils |
| --- | --- | --- |
| Set induction · 5 min | Show a counter two squares across and three squares up from the origin. | State the horizontal and vertical moves in that order. |
| Main activity · 30 min | Model reading across before moving up. Compare (2,3) and (3,2) on a grid, placing different objects at both positions. | Name objects from given coordinates, then write coordinates for named objects. |
| Practice and assessment · 20 min | Place a tree at (2,3), a fountain at (3,2) and a bench at (4,1). Ask what is at (2,3) and for the fountain and bench positions. Check tree, (3,2) and (4,1). | Name the object and give the other two ordered pairs, showing both axis moves for one answer. |
| Closure · 5 min | Ask why the order matters in the pair (2,3). | Point to the different position produced by (3,2). |

**Reflection** · ___ of ___ pupils met the learning objective. Follow-up: ____________________.

## DLP-MAT-Y3-U08-69 · Solve grid location problems

**Standards** · CS 8.2 · LS 8.2.1
**References** · Textbook Part 2 pp. 103–105 · Activity Book pp. 143–144
**Learning objective** · Use a first-quadrant map to solve a clue and justify the location from both axes.
**Materials** · First-quadrant treasure maps, clue strips and two-colour markers.

| Phase | Teacher | Pupils |
| --- | --- | --- |
| Set induction · 5 min | Start at (1,2) and show an arrow three squares right. | Read the new position as (4,2). |
| Main activity · 30 min | Translate clues one move at a time. Keep the horizontal and vertical values labelled and check each move against a landmark. | Trace a route, record its endpoint and swap clues with another pair to verify. |
| Practice and assessment · 20 min | Give a starting point at (1,2), then three squares right and two up. Check (4,4) and the reason each coordinate changed. | Mark the path on a clean grid and justify the endpoint from both axes. |
| Closure · 5 min | Ask which coordinate stays fixed on a horizontal move. | Name the vertical value and point to the unchanged row. |

**Reflection** · ___ of ___ pupils met the learning objective. Follow-up: ____________________.

## DLP-MAT-Y3-R08 · Review: Location

**Standards** · CS 8.1, 8.2 · Review LS 8.1.3, 8.2.1
**References** · Textbook Part 2 pp. 106 · Activity Book pp. 145–146
**Learning objective** · Mark two positions on a first-quadrant grid and write a clue that another pupil can use.
**Materials** · Blank first-quadrant grids, landmark cards and clue slips.

| Phase | Teacher | Pupils |
| --- | --- | --- |
| Set induction · 5 min | Show two landmark cards with coordinates in different orders. | Predict where each belongs and verify by moving across and then up. |
| Main activity · 30 min | Review plotting ordered pairs and writing clues that another pupil can follow. Guide pair checking without revealing endpoints. | Plot two landmarks and exchange a clue to locate one of them. |
| Practice and assessment · 20 min | Give positions (2,4) and (5,1). Check both labels and accept any clue that leads to a marked point from the origin. | Mark both positions and write a reproducible clue for one. |
| Closure · 5 min | Ask a partner to follow a clue aloud. | Verify the endpoint and revise any ambiguous direction. |

**Reflection** · ___ of ___ pupils met the learning objective. Follow-up: ____________________.
