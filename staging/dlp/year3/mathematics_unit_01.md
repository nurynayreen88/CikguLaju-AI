# Mathematics (DLP) · Year 3 SK · Unit 1 Numbers up to 10,000

## DLP-MAT-Y3-U01-01 · Read and match numbers to 10,000

**Standards** · CS 1.1 · LS 1.1.1
**References** · Textbook Part 1 pp. 1–2 · Activity Book pp. 1
**Learning objective** · Read three numbers aloud and match each numeral to the correct words.
**Materials** · Four-digit numeral cards, matching word cards and place-value headings.

| Phase | Teacher | Pupils |
| --- | --- | --- |
| Set induction · 5 min | Show 7,042 and 7,402. Ask which part of each numeral has no hundreds or no tens. | Read the numerals and identify the place occupied by zero. |
| Main activity · 30 min | Model reading 4,306 by grouping thousands and hundreds. Have pairs match a set with zero placeholders and the upper limit 10,000. | Match the word cards to the numeral cards and read each pair aloud. |
| Practice and assessment · 20 min | Give each pupil 1,075, 8,604 and 10,000, with three word cards in a shuffled order. Check the oral reading and each match. | Read and match each numeral independently. |
| Closure · 5 min | Show 9,009. | Read the numeral aloud and point to the two zeros. |

## DLP-MAT-Y3-U01-05 · Compare and order quantities

**Standards** · CS 1.1 · LS 1.1.2 (iii), (iv)
**References** · Textbook Part 1 pp. 9–11, 13 · Activity Book pp. 6–7
**Learning objective** · Use place value to compare two numbers and order four quantities in both directions.
**Materials** · Place-value cards, large number labels and blank ordering strips.

| Phase | Teacher | Pupils |
| --- | --- | --- |
| Set induction · 10 min | Display 3,409 and 3,490. Ask where the comparison can first be decided. | Identify the first differing digit from the left and say which number is greater. |
| Main activity · 45 min | Model comparing from the thousands place. Guide pair practice with number sets of different lengths and then with shared leading digits. Ask pairs to read each set in both orders. | Compare the numbers, place them on a line from least to greatest, then reverse them and explain two pairwise choices. |
| Practice and assessment · 25 min | Give each pupil 5,014, 5,104, 5,041 and 4,999. Check both orders and ask why 5,041 exceeds 5,014. | Order the four numbers in both directions and use the tens digits to justify the comparison. |
| Closure · 10 min | Read the ascending sequence with one deliberate swap. | Correct the position and name the value that settles the comparison. |

## DLP-MAT-Y3-U01-07 · Estimate quantities

**Standards** · CS 1.5 · LS 1.5.1
**References** · Textbook Part 1 pp. 15–16 · Activity Book pp. 9
**Learning objective** · Estimate a collection against a reference group, then count to check the estimate.
**Materials** · Two collections of counters, a known reference group of 20 and counting trays.

| Phase | Teacher | Pupils |
| --- | --- | --- |
| Set induction · 5 min | Show 20 counters beside a larger uncounted group. | Say whether the group seems less than, greater than or about twice 20. |
| Main activity · 30 min | Use repeated groups of 20 to estimate an uncounted collection. Discuss why arrangement can change how large a group looks. | Move or mark reference-sized groups, record an estimate and check it by counting. |
| Practice and assessment · 20 min | Give each pupil a different collection and the same 20-counter reference. Check that the estimate includes a comparison and that the actual count is recorded. | Estimate using about, fewer than or more than, then count and compare with the estimate. |
| Closure · 5 min | Show the same counters spread out. | Explain how the known reference group helps keep the estimate reasonable. |
