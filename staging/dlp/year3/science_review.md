# Science (DLP) · Year 3 SK · Consolidation

## DLP-SCI-Y3-R01 · Review: Humans

**Standards** · CS 3.1, 3.2, 3.3 · Review LS 3.1.1, 3.2.3, 3.3.1
**References** · Textbook pp. 55–58 · Teacher-prepared review prompts
**Learning objective** · Explain the links between teeth, balanced meals and digestion using a diagram.
**Materials** · Diagram sheets and tooth, meal and digestion cards.

| Phase | Teacher | Pupils |
| --- | --- | --- |
| Set induction · 4 min | Show a meal card and ask which teeth help break down a bite. | Name a tooth type and its function. |
| Main activity · 13 min | Guide pairs to link a varied meal, one tooth function and one digestive organ with labelled arrows. | Make a three-part map and compare it with a partner's map. |
| Practice and assessment · 10 min | Give a new meal card and check three correct links on each pupil's diagram. | Independently explain one meal choice, one tooth function and what happens at one digestive organ. |
| Closure · 3 min | Collect one common error and invite a correction. | State the corrected connection. |

## DLP-SCI-Y3-R02 · Review: Animals and Plants

**Standards** · CS 4.1, 5.1 · Review LS 4.1.1, 4.1.2, 5.1.1
**References** · Textbook pp. 69–70, 78 · Teacher-prepared review prompts
**Learning objective** · Sort four examples by diet or reproduction method and explain two selections.
**Materials** · Four example cards, short evidence records and a two-section review sheet.

| Phase | Teacher | Pupils |
| --- | --- | --- |
| Set induction · 4 min | Show a fern and a record of a hen eating insects. | Identify which example calls for a reproduction method and which calls for a diet group. |
| Main activity · 13 min | Review how spore structures or food records support a choice. Guide pairs through one example in each section. | Rehearse explanations based on the visible or written clue. |
| Practice and assessment · 10 min | Check each pupil's four classifications and two explanations, one from each section. | Classify two animals by diet and two plants by reproduction method, then justify a selection in each section. |
| Closure · 3 min | Ask for a clue that helped with one decision. | Name the clue and the resulting group or method. |

**Reflection** · ___ of ___ pupils met the learning objective. Follow-up: ____________________.

## DLP-SCI-Y3-R03 · Review: Measurement, Density and Indicators

**Standards** · CS 6.1, 7.1, 8.1 · Review LS 6.1.5, 7.1.2, 8.1.1
**References** · Textbook pp. 93–94, 104, 113–114 · Teacher-prepared review prompts
**Learning objective** · Correct one measurement and explain a result from a density or litmus table.
**Materials** · A cylinder diagram, a density record and a litmus results card.

| Phase | Teacher | Pupils |
| --- | --- | --- |
| Set induction · 4 min | Show a cylinder with a reading taken from above. | Identify where the observer should look. |
| Main activity · 13 min | Practise correcting a measurement and choosing relevant evidence from a density or litmus table. | Work through one example and explain the correction to a partner. |
| Practice and assessment · 10 min | Give each pupil a fresh cylinder diagram and a choice of density or indicator results. Check both answers and one evidence statement. | Correct the measurement with a unit and explain an observed result from one table. |
| Closure · 3 min | Revisit one common error from the class. | State a specific correction. |

## DLP-SCI-Y3-R04 · Review: Solar System and Machine

**Standards** · CS 9.1, 10.1 · Review LS 9.1.3, 10.1.2
**References** · Textbook pp. 126, 137 · Teacher-prepared review prompts
**Learning objective** · Read one orbit model and explain how changing the direction of a pull lifts a load.
**Materials** · An orbit diagram, pulley model diagram and two short task cards.

| Phase | Teacher | Pupils |
| --- | --- | --- |
| Set induction · 4 min | Show one arrow around the Sun and one arrow beside a rope. | Say what might be moving in each drawing. |
| Main activity · 13 min | Guide pupils to read an orbit path and trace the motion of a fixed pulley. Ask for an explanation tied to each drawing. | Practise showing the path around the Sun and drawing pull and load arrows on a second diagram. |
| Practice and assessment · 10 min | Check each pupil's orbit reading and fixed-pulley arrows, including an explanation of how the pull raises the load. | Answer one orbit question and one pulley problem independently using labelled arrows. |
| Closure · 3 min | Review an answer with conflicting directions. | Correct the arrows and explain the movement. |

**Reflection** · ___ of ___ pupils met the learning objective. Follow-up: ____________________.
