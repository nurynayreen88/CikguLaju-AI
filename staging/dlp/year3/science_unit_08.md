# Science (DLP) · Year 3 SK · Unit 8 Acid and Alkali

## DLP-SCI-Y3-U08-40 · Test substances using litmus

**Standards** · CS 8.1 · LS 8.1.1
**References** · Textbook pp. 106–108 · Activity Book pp. 69–71
**Learning objective** · Record changes to red and blue litmus for three teacher-prepared samples and classify each sample.
**Materials** · Red and blue litmus strips, droppers, labelled lemon juice, baking-soda solution, distilled water and eye protection.

| Phase | Teacher | Pupils |
| --- | --- | --- |
| Set induction · 5 min | Show red and blue strips and ask what to compare in a fair test. | Identify the original colours that must be recorded. |
| Main activity · 30 min | Demonstrate using a fresh dropper and separate strips for each teacher-prepared sample. Supervise tests and keep samples away from mouths and eyes. | Test both strip colours for each sample and record colour changes or no change. |
| Practice and assessment · 20 min | Check each pupil's three-row table against the observed two-strip outcomes and classifications. | Classify the three samples from the recorded evidence and explain one result using both strips. |
| Closure · 5 min | Ask why a single unchanged strip cannot always show neutrality. | Explain that results from both colours are needed. |

## DLP-SCI-Y3-U08-41 · Compare reported properties safely

**Standards** · CS 8.1 · LS 8.1.2
**References** · Textbook pp. 109–111 · Activity Book pp. 72–74
**Learning objective** · Compare the reported properties of three named substances and explain why test results are needed to classify an unknown.
**Materials** · Teacher-supplied property cards for familiar materials and a verified litmus results chart.

| Phase | Teacher | Pupils |
| --- | --- | --- |
| Set induction · 5 min | Show cards for sour lemonade, plain water and a slippery soap solution. | Describe only the printed observations. |
| Main activity · 30 min | Compare the descriptions and the verified chart. Explain that some familiar examples share properties, but a reported taste or feel alone cannot classify an unknown liquid. | Compare acidic, neutral and alkaline examples using the evidence cards and litmus results. Keep the property descriptions tied to the named samples. |
| Practice and assessment · 20 min | Check each pupil's table for three comparisons and an explanation of which evidence should be used for an unknown. | Write a conclusion that uses litmus evidence to classify an unknown sample and explains the limits of the reported descriptions. |
| Closure · 5 min | Give a card with only the description clear. | Name the additional test evidence needed. |

## DLP-SCI-Y3-U08-42 · Compare other indicators

**Standards** · CS 8.1 · LS 8.1.3
**References** · Textbook pp. 112 · Activity Book pp. 75
**Learning objective** · Compare the colour changes of a teacher-prepared plant indicator and litmus for the same samples.
**Materials** · Teacher-prepared purple cabbage indicator, litmus, droppers and three familiar labelled dilute samples.

| Phase | Teacher | Pupils |
| --- | --- | --- |
| Set induction · 5 min | Show the starting colour of the plant indicator and ask how to check what any change means. | Suggest comparing it with an established test on the same samples. |
| Main activity · 30 min | Demonstrate testing equal aliquots of each familiar sample with separate droppers. Explain how comparison with litmus helps interpret the plant indicator. | Use the same known samples for both tests. Record the observed colours side by side. |
| Practice and assessment · 20 min | Check each pupil's table for three paired observations and one conclusion consistent with those observations. | Identify one result where the two tests support the same classification and explain the evidence. |
| Closure · 5 min | Ask why the original indicator colour is recorded. | Explain how it provides a comparison for observed changes. |

## DLP-SCI-Y3-U08-43 · Report indicator results

**Standards** · CS 8.1 · LS 8.1.4
**References** · Textbook pp. 111–114 · Activity Book pp. 75–76
**Learning objective** · Summarise results in a three-row table and draw a conclusion based on colour changes.
**Materials** · Three sample result cards, a class results chart and report sheets.

| Phase | Teacher | Pupils |
| --- | --- | --- |
| Set induction · 5 min | Show an unnamed row with both litmus results. | Interpret the evidence and propose a classification. |
| Main activity · 30 min | Model how to record the initial and final colours and a conclusion. Give pairs a table that includes an incorrect classification to correct. | Explain the correction with reference to the observed colours. |
| Practice and assessment · 20 min | Check each pupil's independent table for three classifications and a conclusion supported by a recorded pair of observations. | Summarise all three results and explain one classification using the recorded changes. |
| Closure · 5 min | Ask what the results show when neither colour changes. | Identify the neutral result within this set of tested samples. |
