# Science (DLP) · Year 2 SK · Unit 10 Technology

Six 60-minute RPH for CS 10.1. See the [source mapping](../../../audits/dlp_sk_sources_20261114.md#year-2-unit-10-source-check).

## DLP-SCI-Y2-U10-01 · Choose a Model From a Building Set

**Standards** · CS 10.1 · LS 10.1.1
**References** · Textbook pp. 117–119 · Activity Book p. 77
**Learning objective** · Choose a model that the available building set can make and verify the choice using a picture in the set's manual or on its box.
**Materials** · Classroom building sets with illustrated manuals, photographs of possible models and individual choice slips.

| Phase | Teacher | Pupils |
| --- | --- | --- |
| Set induction · 5 min | Show two models assembled from the same set and ask how one box can make both. | Describe how the same pieces can be arranged in different ways. |
| Main activity · 30 min | Guide pairs to compare pictures on the boxes and in the manuals. Model checking the same set's manual when a model is pictured on a different box. | Find two models their set can make, choose one and show a partner where the model appears. |
| Practice and assessment · 20 min | Give each pupil a set and three model choices, including an option from a different set. Check the selected model against the box or manual. | Independently name a model their set can make and point to the matching picture as evidence. |
| Closure · 5 min | Ask what a pupil should look at before choosing a model for the next lesson. | Name the box or illustrated manual and state what to check. |

**Reflection** · ___ of ___ pupils selected a model and verified it against the correct set. Guide pupils who chose a model from another set to match the pictures with the correct manual.

## DLP-SCI-Y2-U10-02 · Identify the Parts Shown in a Manual

**Standards** · CS 10.1 · LS 10.1.2
**References** · Textbook pp. 120–121 · Activity Book p. 78
**Learning objective** · Identify three component types in an illustrated manual and collect the exact quantity of each shown for the selected model.
**Materials** · Building sets, illustrated manuals for the selected models, sorting trays and simple component lists.

| Phase | Teacher | Pupils |
| --- | --- | --- |
| Set induction · 5 min | Show a short connector and a longer connector that look similar in the manual. Ask which features help distinguish them. | Compare the length or number of joining points and point to the matching illustration. |
| Main activity · 30 min | Model reading the part pictures and quantities before picking pieces. Use the instructions to check parts that differ only in size or shape. | Match pictures to pieces, count each type into a tray and check the quantities with a partner. |
| Practice and assessment · 20 min | Give each pupil a manual panel containing three component types and a mixed tray. Check their selection against the actual panel. | Independently select the three correct types and quantities and point to the source of each count. |
| Closure · 5 min | Ask what to do if a piece looks similar but has a different number of joining points. | Compare the piece with the manual and select the one with the matching features. |

**Reflection** · ___ of ___ pupils selected all three types and their exact quantities. Revisit the relevant illustration with pupils who confused similar pieces.

## DLP-SCI-Y2-U10-03 · Assemble a Model From Illustrated Instructions

**Standards** · CS 10.1 · LS 10.1.3
**References** · Textbook pp. 122–123 · Activity Book pp. 79–80
**Learning objective** · Follow at least three successive illustrated steps to assemble a model and verify the finished arrangement against the manual.
**Materials** · Classroom building kits with a small model, illustrated manuals and a teacher observation checklist.

| Phase | Teacher | Pupils |
| --- | --- | --- |
| Set induction · 5 min | Show two consecutive illustrations with a new piece in the second panel. Ask how to spot what was added. | Compare the pictures and point to the new piece and its position. |
| Main activity · 30 min | Model orienting the part as shown and checking the result after each step. Give pairs a short model to practise, with each pupil taking a turn assembling and checking. | Use the manual in order, select and connect the pieces, and compare the model with the current illustration before moving on. |
| Practice and assessment · 20 min | Give each pupil a prepared kit and a small model with at least three pictured steps. Observe their order and compare the result with the final illustration. | Independently follow the steps and point out one connection that matches the final picture. |
| Closure · 5 min | Ask how to find the first error if the completed model looks different from the picture. | Suggest comparing the model with earlier panels to locate the first mismatch. |

**Reflection** · ___ of ___ pupils followed the illustrated sequence and assembled a model that matched the manual. Practise reorienting one part with pupils whose connections did not match.

## DLP-SCI-Y2-U10-04 · Design and Build an Original Model

**Standards** · CS 10.1 · LS 10.1.4
**References** · Textbook pp. 124–125 · Activity Book p. 81
**Learning objective** · Sketch and build a model absent from the kit's illustrated manual, then demonstrate or explain a function of the model.
**Materials** · Building sets, their manuals, sketch paper and a simple design checklist.

| Phase | Teacher | Pupils |
| --- | --- | --- |
| Set induction · 5 min | Show how the same set of pieces can make two different outlines. Ask what another useful model could represent. | Suggest a model and say what it could do. |
| Main activity · 30 min | Ask pupils to scan their kit manual and choose a design absent from it. Prompt them to plan a base and one feature linked to the intended function. | Sketch a plan, choose components and build their model. Revise a loose connection or unstable base after checking it. |
| Practice and assessment · 20 min | Ask each pupil to show the sketch and model, check the design against the manual and explain a feature. | Independently present the original model and demonstrate or describe its function, such as how a wide base helps support a tower. |
| Closure · 5 min | Ask which part of the first sketch changed during construction. | Identify a change and explain what the change improved. |

**Reflection** · ___ of ___ pupils built an original model and explained a function. Help pupils whose builds stopped at a sketch to choose and test one workable connection.

## DLP-SCI-Y2-U10-05 · Disassemble and Store a Model in Order

**Standards** · CS 10.1 · LS 10.1.5
**References** · Textbook pp. 126–127 · Activity Book pp. 82–83
**Learning objective** · Remove pieces in reverse assembly order, sort them by type, check the count against the kit inventory and return them to the correct compartments.
**Materials** · Small assembled models, illustrated manuals or assembly records, compartment trays and count lists.

| Phase | Teacher | Pupils |
| --- | --- | --- |
| Set induction · 5 min | Show a model with a top piece covering a connection. Ask which piece to remove first and why. | Identify the last-added part and explain how removing it reveals the connection below. |
| Main activity · 30 min | Demonstrate working backwards through the assembly pictures. Model sorting the removed pieces, checking counts and placing each type in its labelled compartment. | Practise the reverse sequence and compare sorted groups with the inventory before storing them. |
| Practice and assessment · 20 min | Observe each pupil disassemble a small model. Check the first part removed, the sorting, the inventory check and the final compartment placement. | Independently remove the pieces in order, sort and count them, then place them in their compartments and report a discrepancy if one appears. |
| Closure · 5 min | Ask what to do if the count is one short. | Recheck the tray and work area, then tell the teacher which piece is missing. |

**Reflection** · ___ of ___ pupils disassembled, counted and stored their sets correctly. Revisit the last assembly step or the relevant compartment with pupils who missed either check.

## DLP-SCI-Y2-U10-06 · Explain Observations About a Built Model

**Standards** · CS 10.1 · LS 10.1.6
**References** · Textbook pp. 124–125 · Activity Book p. 84
**Learning objective** · Communicate two observations about a built model and explain how one visible feature affects the way it works or stands.
**Materials** · Completed classroom models, their planning sketches, observation cards and pencils.

| Phase | Teacher | Pupils |
| --- | --- | --- |
| Set induction · 5 min | Show a model with a wide base and ask pupils to describe what they see before offering a reason. | Name a visible feature and distinguish it from a suggested explanation. |
| Main activity · 30 min | Model explaining a feature using evidence from a demonstration, such as comparing how a model stands before and after a support is added. | Observe their own model, record two visible details and discuss which detail helps explain a result. |
| Practice and assessment · 20 min | Ask each pupil for a labelled sketch, short written explanation or oral response. Check two observations and one feature-to-function link against the model. | Independently report two observations and explain how one part helps the model work, stay joined or stand upright. |
| Closure · 5 min | Ask pupils to point to the detail in their response that supports the explanation. | Identify the evidence and state what it shows about the model. |

**Reflection** · ___ of ___ pupils gave two observations and explained one feature using evidence. Revisit the model with pupils who named a part without explaining its effect.
