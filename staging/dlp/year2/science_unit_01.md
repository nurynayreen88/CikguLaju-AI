# Science (DLP) · Year 2 SK · Unit 1 Scientific Skills

These four CikguLaju lesson plans cover Science Process Skills (CS 1.1) in the KSSR (Semakan 2017) English-edition DSKP. Each plan is 60 minutes. The codes identify staging records. Source mapping and the remaining checks are recorded in the [DLP audit](../../../audits/dlp_sk_sources_20261114.md#year-2-batch-1-source-check).

## DLP-SCI-Y2-U01-01 · Observe

**Standards** · CS 1.1 · LS 1.1.1 (Observe)  
**References** · Textbook pp. 2–4 · Activity Book pp. 1–2  
**Learning objective** · Record three relevant observations and name the sense used for each.  
**Materials** · A fabric swatch, a wooden block, a closed shaker, pencils and a three-row observation table.

| Phase | Teacher | Pupils |
| --- | --- | --- |
| Set induction · 5 min | Show a swatch and a block. Ask which properties pupils can identify using sight or touch. | Describe one visible property and one property they can feel. |
| Main activity · 30 min | Model one observation using “I notice … using …”. Guide pairs through three stations for sight, touch and hearing. | At each station, observe one item, record its property and name the sense used. Compare entries with a partner. |
| Practice and assessment · 20 min | Check three entries per pupil for a property and a matching sense. Give prompts where an entry is a guess. | Refer to Activity Book pp. 1–2 if available. Independently submit three property-and-sense pairs. |
| Closure · 5 min | Ask pupils to give one observation that another person could check. | Share a property and name how they checked it. |

**Reflection** · ___ of ___ pupils recorded three valid pairs. Follow up with a guided property-and-sense match.

## DLP-SCI-Y2-U01-02 · Classify

**Standards** · CS 1.1 · LS 1.1.2 (Classify)  
**References** · Textbook pp. 5–7 · Activity Book pp. 3–4  
**Learning objective** · Sort six pictures into two groups using one observable feature and state the rule used.  
**Materials** · Animal picture cards and two sorting mats per pair. Use clear full-body pictures.

| Phase | Teacher | Pupils |
| --- | --- | --- |
| Set induction · 5 min | Show a duck and a goat. Ask pupils to identify a feature visible in one picture only. | Point to a feature and describe the difference. |
| Main activity · 30 min | Model how one feature produces two groups. Give pairs six cards and ask them to check each card against their rule. | Sort the cards, label each group and explain one decision to a partner. Test a second feature if time permits. |
| Practice and assessment · 20 min | Give pictures of a chicken, an owl, a parrot, a cat, a horse and a rabbit. Check that the labels express opposite outcomes of one visible feature and all six placements follow the rule. | Refer to Activity Book pp. 3–4 if available. Individually sort the new pictures, then write or say the rule. |
| Closure · 5 min | Move one card to the wrong group and ask for a correction. | Move the card back and justify the placement using the feature. |

**Reflection** · ___ of ___ pupils sorted all six cards and stated a consistent rule. Revisit one observable feature with pupils who changed rules halfway.

## DLP-SCI-Y2-U01-03 · Measure and Use Numbers

**Standards** · CS 1.1 · LS 1.1.3 (Measure and use numbers)  
**References** · Textbook pp. 8–10 · Activity Book pp. 5–6  
**Learning objective** · Measure two straight paper strips to the nearest centimetre and record both readings with the correct unit.  
**Materials** · 30 cm rulers, pre-cut strips in whole-centimetre lengths and a two-row recording table.

| Phase | Teacher | Pupils |
| --- | --- | --- |
| Set induction · 5 min | Show two strips with different starting positions. Ask how to compare their lengths fairly. | Suggest lining up the ends and using the same ruler. |
| Main activity · 30 min | Demonstrate aligning an end to the zero mark and reading the other end from above. Deliberately start at the 1 cm mark and ask pupils to identify the error. | Take turns measuring and checking with a partner. Record each length in a table with the unit cm. |
| Practice and assessment · 20 min | Give each pupil two unmarked strips of 8 cm and 14 cm. Check ruler placement and both readings. | Refer to Activity Book pp. 5–6 if available. Independently measure the two strips and label both readings with cm. |
| Closure · 5 min | Ask what information is missing if a measurement is written as “12”. | Give the unit and explain where to place the strip to start. |

**Reflection** · ___ of ___ pupils recorded both measurements with the correct unit. Reteach zero alignment using a marked start line where needed.

## DLP-SCI-Y2-U01-04 · Communicate

**Standards** · CS 1.1 · LS 1.1.4 (Communicate)  
**References** · Textbook pp. 10–11 · Activity Book pp. 7–8  
**Learning objective** · Present two accurate findings from a tally using a labelled table and one spoken or written comparison.  
**Materials** · Bags of coloured counters, tally sheets and pencils.

| Phase | Teacher | Pupils |
| --- | --- | --- |
| Set induction · 5 min | Show an unlabelled tally. Ask what a reader needs to know to interpret it. | Suggest labels for what was counted and the number counted. |
| Main activity · 30 min | Give groups counters in three colours. Model the first table row and ask how the row helps a listener understand the findings. | Count the counters, agree on totals and take turns explaining a finding using their table. |
| Practice and assessment · 20 min | Give each pupil a new tally showing four red, six blue and two yellow counters. Check the headings, the red and blue totals, and the comparison. | Refer to Activity Book pp. 7–8 if available. Convert the tally into a labelled table independently, then report the red and blue totals and say which colour has more. |
| Closure · 5 min | Ask what would make a classmate's table easy to understand. | Identify one useful feature, such as clear category headings. |

**Reflection** · ___ of ___ pupils reported two accurate totals and a correct comparison. Revisit the use of headings and reading across a row.
