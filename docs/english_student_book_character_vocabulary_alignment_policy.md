# English Year 2–3 — Student's Book Character and Vocabulary Alignment Policy

**Status:** Mandatory staging QA policy; not a claim that all existing resources have passed verification.

1. Treat the correct year and unit Student's Book as the primary reference for named characters, story settings, recurring objects, vocabulary and language patterns.
2. When a lesson explicitly follows a Student's Book story or character activity, use the actual verified character names. Do not substitute invented names.
3. For NON-TEXTBOOK lessons, use vocabulary, situations and grammatical structures appropriate to the current Student's Book unit and pupils' level. Do not present invented characters or narratives as official Student's Book material.
4. Clearly label original teacher-created passages, dialogues and assessment scripts. Avoid unverified textbook page, character or audio claims.
5. Review existing Year 2 material packs before READY, prioritising teacher-created stories with named characters: Lessons 016 (Aina), 018 (Hana), 028 (Adam/Sara), 036 (Mia), 045 (Aina/Ben), 046 (house narration), 047 (Nina), and other lesson packs containing names or potentially off-unit vocabulary.
6. Where the actual Student's Book character list or unit vocabulary has not been inspected, mark `SB_ALIGNMENT_PENDING`. Do not guess replacements or overwrite original RPH.
7. QA checklist per pack: Year/Unit; SB page or unit evidence; official character names if applicable; vocabulary list; language pattern; age appropriateness; RPH SK/SP/objectives; learning material; assessment and key; print and bot download tests.
8. All corrections are non-destructive: retain original RPH, stage amended material files with clear provenance and audit trail. READY only after verification and print/download tests.

**Immediate note:** Prior teacher-created resources can be useful drafts but must not be described as Student's Book aligned merely because their general topic matches.
