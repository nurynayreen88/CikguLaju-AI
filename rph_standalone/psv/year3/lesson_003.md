# RPH Pendidikan Seni Visual Tahun 3 — PdP 003
**Status:** DRAF SEMAK (sasaran mutu 90%)  
**Unit:** 1 — Tut Tut Kereta Api  
**Fokus:** Penghasilan karya seni | **Teknik:** Lukisan silang pangkah  
**SK:** 3.1  
**SP:** 3.1.1  
**Rujukan Buku Teks:** Pendidikan Kesenian Tahun 3 (bahagian Seni Visual) ms 8–9 (unit 6-9)  
**BBM:** BT ms 8–9, kertas lukisan, pensel grafit, pensel warna dan pemadam
**Tempoh:** 60 minit

## Objektif dan kriteria kejayaan
Murid dapat menghasilkan lukisan Tut Tut Kereta Api dengan garisan silang pangkah yang menunjukkan ruang dan asap bergerak. Evidens PBD: Lukisan kereta api lengkap, dua kesan silang pangkah, roda berlapis dan asap beralun.

## Langkah PdP
**Set induksi (5 minit):** Guru menunjukkan contoh Tut Tut Kereta Api dan murid memberi satu pemerhatian tentang bentuk, warna, ruang atau fungsi.
**Aktiviti 1 (15 minit) — Tunjuk cara:** Guru menunjukkan BT ms 8–9: lakar bentuk kereta api dengan garisan pelbagai, susun kedudukan roda, lukis asap dan tambah silang pangkah untuk kesan ruang.
**Aktiviti 2 (25 minit) — Amali:** Murid melakar lokomotif dan roda pada kertas, menambah asap beralun, kemudian mengisi bahagian badan dan latar dengan garisan silang pangkah rapat-jarang bagi mewujudkan ruang.
**Pengukuhan/Pentaksiran (10 minit):** Guru menilai kedudukan roda yang menunjukkan ruang, asap berpergerakan dan dua perbezaan ton daripada silang pangkah.
**Penutup (5 minit):** Murid menyebut satu teknik yang dipelajari; guru membimbing penyimpanan hasil dan pembersihan.
**Pembezaan:** Kad langkah bergambar untuk sokongan; murid lanjutan menghuraikan pilihan media dan kesan visual.
**Keselamatan:** Pensel dan alat tulis digunakan di meja; guru mengendalikan pengasahan pensel, murid tidak melukis dengan hujung tajam menghala rakan.
