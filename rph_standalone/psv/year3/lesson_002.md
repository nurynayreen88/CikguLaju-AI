# RPH Pendidikan Seni Visual Tahun 3 — PdP 002
**Status:** DRAF SEMAK (sasaran mutu 90%)  
**Unit:** 1 — Tut Tut Kereta Api  
**Fokus:** Percubaan media dan idea lakaran | **Teknik:** Lukisan silang pangkah  
**SK:** 2.1; 3.1  
**SP:** 2.1.1; 3.1.1  
**Rujukan Buku Teks:** Pendidikan Kesenian Tahun 3 (bahagian Seni Visual) ms 8–9 (unit 6-9)  
**BBM:** Buku Teks ms 8–9, pensel grafit/warna, kertas lukisan, contoh roda dan asap kereta api
**Tempoh:** 60 minit

## Objektif dan kriteria kejayaan
Murid dapat merancang dua lakaran kereta api dengan roda berbeza kedudukan dan asap yang menunjukkan pergerakan. Evidens PBD: Dua lakaran berlabel, dua jenis garisan dan satu alasan pilihan komposisi.

## Langkah PdP
**Set induksi (5 minit):** Guru menunjukkan contoh Tut Tut Kereta Api dan murid memberi satu pemerhatian tentang bentuk, warna, ruang atau fungsi.
**Aktiviti 1 (15 minit) — Tunjuk cara:** Guru menunjukkan BT ms 8–9: lukis rupa kereta api dengan garisan melengkung serta beralun, tegaskan kedudukan roda dan pergerakan asap.
**Aktiviti 2 (25 minit) — Amali:** Murid melakar dua susunan lokomotif, menandakan roda di ruang hadapan-belakang dan asap beralun, kemudian memilih lakaran untuk silang pangkah.
**Pengukuhan/Pentaksiran (10 minit):** Guru memeriksa dua lakaran, garisan melengkung/beralun dan alasan memilih susun atur.
**Penutup (5 minit):** Murid menyebut satu teknik yang dipelajari; guru membimbing penyimpanan hasil dan pembersihan.
**Pembezaan:** Kad langkah bergambar untuk sokongan; murid lanjutan menghuraikan pilihan media dan kesan visual.
**Keselamatan:** Pensel dan alat tulis digunakan di meja; guru mengendalikan pengasahan pensel, murid tidak melukis dengan hujung tajam menghala rakan.
