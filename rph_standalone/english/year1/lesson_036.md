# ENGLISH YEAR 1 — STANDALONE RPH

**Lesson:** 36 — Listening 8  
**Unit:** At School  
**Main SK / SP:** 1.2 / 1.2.2  
**Complementary SK / SP:** 2.1 / 2.1.1  
**Learning objective:** Practise listening/reading for specific information and present This is my desk / There's a ... .  
**Teaching materials:** Student's Book pp. 16, Workbook activity; Teacher's Book pp. 16  
**Audio guidance:** SB p16 uses CD1 Track 25.

### Set Induction
**Teacher:** Review classroom objects with a hidden drawing/guessing game using Is it a ...?.
**Pupils:** Respond to prompts and demonstrate recalled language.

### Activity 1 — Student's Book
**Teacher:** On SB p16 listen to five children describing desks, draw lines to match speakers/desks, compare in pairs and replay to check.
**Pupils:** Listen to five desk descriptions; match speakers to desk pictures and explain the clues.

### Activity 2 — Workbook
**Teacher:** WB p16: read descriptions and mark each statement with a tick or cross.
**Pupils:** Complete the specified Workbook task and compare answers.

### Assessment / PBD
**Teacher:** Pairs compare listening matches before class checking; ask pupils to justify choices using visible desk objects.
**Pupils:** Provide responses and explain or correct answers during checking.

### Closure
**Teacher:** Build an oral chain beginning This is my desk. There's a ... and add one object each turn.
**Pupils:** Participate in the specified consolidation task.
