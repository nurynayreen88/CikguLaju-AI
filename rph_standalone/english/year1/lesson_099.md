# English Year 1 — Standalone RPH: Lesson 99

**Unit:** Pet Show  
**Skill:** Writing 20  
**Main SK/SP:** 4.2 / 4.2.3  
**Complementary SK/SP:** 4.2 / 4.2.5  
**Objective:** Practise Unit 3 language in a writing-focused textbook task.  
**Measurable objective (teacher-developed, pending review):** By the end of the lesson, pupils can produce one short written response following the SB p40 model.
**Student's Book:** 40

## Activity 1 — Textbook sequence
**Teacher:** Use the SB p40 writing model to demonstrate the guided task, then supervise pupils' short individual writing.
**Pupils:** Study the writing model on SB p40, complete the guided task, then write a short individual response using the modelled language.

## Assessment / PBD
**Observable evidence (teacher-developed):** Check each pupil's writing for task relevance and one accurate modelled word or pattern.
**Teacher:** Use pair checking for target vocabulary and the modelled language pattern before class feedback.
**Pupils:** Give responses and explain or correct them during checking.

## Closure — Teacher-developed proposal (not verified Teacher's Book)
**Teacher:** Ask pupils to read their writing to a partner and check it against the model.
**Pupils:** Read the short written response to a partner and check that it follows the SB p40 model.
