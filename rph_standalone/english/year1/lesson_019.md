# ENGLISH YEAR 1 — STANDALONE RPH

**Lesson:** 19 — Speaking 4  
**Unit:** At School  
**Main SK / SP:** 2.1 / 2.1.5  
**Complementary SK / SP:** 1.2 / 1.2.2  
**Learning objective:** Practise asking and answering about classroom objects using What's this? and Is it a ...?.  
**Teaching materials:** Student's Book pp. 11, Workbook activity; Teacher's Book pp. 11  
**Audio guidance:** SB p11 uses CD1 Tracks 14 and 15; WB p11 uses CD1 Track 16.

### Set Induction
**Teacher:** Display classroom-object flashcards with deliberately mismatched labels and let pupils correct them.
**Pupils:** Respond to prompts and demonstrate recalled language.

### Activity 1 — Student's Book
**Teacher:** Use SB p11 listening to number the pictures, model the target questions and answers with real objects, replay for choral repetition, then run the guessing game in groups.
**Pupils:** Follow the Student's Book task, practise the target classroom language with a partner and respond to the teacher's checks.

### Activity 2 — Workbook
**Teacher:** WB p11: listen and write the classroom-object words, then read statements and tick the correct box.
**Pupils:** Complete the specified Workbook task and compare answers.

### Assessment / PBD
**Teacher:** Pupils check listening answers in pairs before whole-class confirmation; repeat target exchanges aloud.
**Pupils:** Provide responses and explain or correct answers during checking.

### Closure
**Teacher:** Slowly draw familiar items on the board while pupils guess using the target question pattern.
**Pupils:** Participate in the specified consolidation task.
