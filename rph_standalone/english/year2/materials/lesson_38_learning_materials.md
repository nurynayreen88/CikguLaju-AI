# English Year 2 — lesson 38 learning materials.md

Original teaching resource aligned with the existing standalone lesson. Official SOW and printable QA pending.

Prepare phonics cards bed, cat, stop and clap. Model phoneme segmentation and blending, tapping one sound at a time. Pupils practise the four words and echo target sounds. Optional extension uses room vocabulary: kitchen, bedroom, bathroom, living room, stairs, cellar, table and sofa. Keep phonics as the core activity.

Use the existing lesson timing and record independent PBD evidence. Do not show teacher keys before assessment.
