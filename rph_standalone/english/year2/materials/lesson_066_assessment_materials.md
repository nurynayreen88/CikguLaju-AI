# Lesson 066 — Assessment Materials

Using the Student's Book p.84 illustration, give two spoken messages with clear pointing and ask pupils to select the correct clothing items. Then ask each pupil to describe two visible clothing objects by item and colour. Record listening with visual support 0–2 and accurate spoken descriptions 0–2, including prompts.
