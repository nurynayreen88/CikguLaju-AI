# English Year 2 Lesson 46: Assessment Materials

**Skill:** Listening. Original teacher-developed content based on the current standalone RPH; SOW and PDF QA pending.

Read the script without displaying it. Assess three correctly placed objects with correct details: kitchen round table, bedroom two beds, living room green sofa. Ask pupil to describe one room orally. Key is those three placements; accept there is a round table / there are two beds / there is a green sofa. Record objects /3, oral description accurate Y/N, support.

**Timing:** Set induction 5 min, model 15 min, guided activity 25 min, individual assessment 10 min, closure 5 min. Keep assessment evidence separate from guided practice.
