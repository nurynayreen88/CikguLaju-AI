# Year 2 English Lesson 060 — Learning resource

Unit: Get dressed!
Focus: Language Arts and spelling.

Teacher-made short text:

A child has a red cap. A friend has blue shoes. The child puts on a jacket. The friend picks up socks.

Pupils listen and identify one person, one thing and one action from the text. They then practise spelling cap, shoes, jacket and socks. The text deliberately uses unnamed characters because the Student's Book characters have not been verified.

This is an original classroom resource, not a quotation from Student's Book.
