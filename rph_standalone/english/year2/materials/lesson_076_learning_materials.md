# Lesson 076 — Reading practice

Use Super Minds 1 Student's Book page 88. Pupils read six yes/no statements about the children in the bus picture. Ask them to reread and find the pictured evidence for each answer. The Teacher's Book answer sequence is: yes, no, no, no, yes, no. Workbook page 88 has an optional poem activity. The original Hana passage is a teacher-created alternative, not the book activity.
