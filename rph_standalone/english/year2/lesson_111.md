# English Year 2 — Lesson 111: Listening 23

**Unit:** The robot
**Main SK/SP:** 1.2 / 1.2.5
**Complementary SK/SP:** 1.3 / 1.3.1
**Learning objectives:** Pupils identify the main idea of a short spoken robot description and respond to three simple listening prompts.
**Success criteria:** one accurate main-idea choice and three relevant responses.
**Teaching materials:** Two robot cards, board, individual response sheet.

**Original listening script:** “This robot works in a school library. It has two arms and four wheels. Every morning it carries books to the shelves.” **Main idea choices:** A A robot helping in a library; B A robot cooking dinner; C A robot playing football. **Key:** A. **Three prompts and keys:** Where does it work?—library. How many wheels?—four. What does it carry?—books.
**Audited source mapping:** NON-TEXTBOOK / SOW task (Year 2 audit); detailed procedure not yet verified.

## Set Induction (5 minutes)
**Teacher (5 min):** Display a robot picture and elicit familiar vocabulary.
**Pupils:** Name two robot features.

## Activity 1 — Modelling (15 minutes)
**Teacher (15 min):** Model listening for the main idea of a short teacher-created robot description.
**Pupils:** Practise one supported response.

## Activity 2 — Guided practice (25 minutes)
**Teacher (25 min):** Read the original library-robot script twice; pupils select the main idea and answer all three scripted prompts.
**Pupils:** Select the main idea and respond to three prompts.

## Assessment / PBD (10 minutes)
**Teacher (10 min):** Check one main-idea selection and three oral answers per pupil, noting independent accuracy.
**Pupils:** Submit individual evidence.

## Closure (5 minutes)
**Teacher (5 min):** Review one useful robot expression.
**Pupils:** Share one new word or phrase.
