# English Year 3 — Lesson 39: Speaking

**Unit:** Right Now
**Main SK/SP:** Speaking 2.1 / 2.1.5
**Complementary SK/SP:** Speaking 2.2 / 2.2.2
**Duration:** 60 minutes
**References:** Student's Book p.27 Activity 4; Teacher's Book p.49; picture and sentence matching cards.
**Learning objective:** Describe an action picture and use a suitable question to ask a classmate or teacher for help.
**Success criteria:** One intelligible action description and one appropriate spoken request for help.

## Set Induction (5 minutes)
**Teacher:** Show written action phrases beside picture prompts.
**Pupils:** Read a phrase and choose the matching picture.

## Activity 1 — Matching game (15 minutes)
**Teacher:** Give groups face-down picture and sentence cards and model one turn.
**Pupils:** Turn over two cards, read the sentence and explain whether it matches the picture.

## Activity 2 — Ask, answer and guess (25 minutes)
**Teacher:** Model Student’s Book p.27 Activity 4 and a polite help question. Give each group a secret picture card.
**Pupils:** Offer a clue, ask the group to guess the action and request help if a word is missing.
**Workbook:** Use the example and item 6 in Workbook p.19, Activity 2, for oral practice before writing.

## PBD (10 minutes)
**Teacher:** Listen to a picture description and set up a turn where each pupil needs help with a word.
**Pupils:** Describe one action clearly and ask a partner or teacher a suitable help question.

## Closure (5 minutes)
**Teacher:** Write one common error heard during the game.
**Pupils:** Suggest a correction and say the improved sentence.
