# English Year 3 — Lesson 107: Listening

**Unit:** Out and About
**Main SK/SP:** 1.2 / 1.2.2
**Complementary SK/SP:** 1.2 / 1.2.1
**Duration:** 60 minutes
**References:** Student's Book p.69; Teacher's Book pp.106–107; rule flashcards.

## Set Induction (5 minutes)
Teacher reviews familiar classroom rules with gestures.

## Activity 1 (15 minutes)
Teacher leads a listening game using rule flashcards. Pupils identify the correct sign.

## Activity 2 (25 minutes)
Teacher guides Activity 2. Pupils listen to classmates read their rules and mark rules that match their own lists.

## Assessment / PBD (10 minutes)
Teacher reads three classroom rules. Pupils identify the matching signs and name one rule shared with a classmate; teacher records individual responses.

## Closure (5 minutes)
Pupils state one shared classroom rule.
