# Year 5 Lesson 158 — Writing 27

**Official SOW topic:** Going away.

Status: DRAF. Unit 8. Main LS 4.2.3; complementary LS 2.1.2.
Materials: Student Book p.111 Activities 4–5; Teacher Book p.125; three Malaysian theme park fact files. Workbook mapping and audio playback remain unverified.

Objective: Pupils use a three-park comparison table to write a short factual description with appropriate superlatives and describe one park feature orally to another group.

Set induction (5 min): Recall theme-park facts and superlative adjectives.

Main activities (40 min): Groups compare information about three theme parks, complete a fact table, then write a factual description. Mixed groups explain experiences and recommend a ride. Teacher models instructions and provides feedback.

PBD (10 min): Teacher checks the fact table and a written description for correct park information and at least one suitable superlative, and observes the oral information exchange.

Closure (5 min): Pupils share a learning point and submit an exit response.

Differentiation: Use visuals, sentence frames and paired support where needed; extend confident pupils with detailed independent work.
