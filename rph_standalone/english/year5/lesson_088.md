# English Year 5 Lesson 88: Project 1

Official SOW Lesson 88, printed p.127. Topic: Teacher-selected project. Suggested duration: 60 minutes.
Standards: SOW does not assign fixed standards; teacher selects DSKP main and complementary skills.
Materials: PROJECT-BASED NON-TEXTBOOK: teacher-selected materials and topic.

1. Set induction (8 min): Discuss pupil interests and agree a suitable project question.
2. Activity 1 (12 min): Teacher selects relevant Year 5 DSKP standards and success criteria.
3. Activity 2 (15 min): Groups plan project steps, materials and roles.
4. Activity 3 (17 min): Groups create a project product and record progress.
5. PBD and closure (8 min): Present products and reflect using the selected criteria.

PBD: Assess work against the stated or teacher-selected skills.
Differentiation: This is a CikguLaju suggested project framework, not prescribed SOW activities.
