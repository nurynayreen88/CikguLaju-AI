# English Year 6 — Lesson 160: Teacher to select (Project-Based Learning 2)

**Year:** 6  
**RPT:** 2027, Lesson 160, M40 (week indicative only)  
**Main CS/LS:** PILIHAN GURU (SOW)  
**Complementary CS/LS:** PILIHAN GURU (SOW)  
**Language focus:** relevant vocabulary and language from this unit  
**Duration:** 60 minutes  
**Materials:** Project-Based Learning 2 teacher-choice task; A4 paper, markers and presentation checklist  
**Learning objective:** Create a three-entry end-of-year story portfolio with past-tense recounts; present one memory for 1 minute.
**PBD evidence:** Three school-event entries (when/where/what), two past-tense sentences each and a 1-minute reflection.

## Set induction (5 minutes)
**Teacher:** Show three mixed-up school-event captions; ask for the correct order.
**Pupils:** Order captions and name one school memory.

## Activity 1 — Prepare (10 minutes)
**Teacher:** Model a four-box recount planner (when, where, event, feelings).
**Pupils:** Select three school memories, assign roles and outline entries.

## Activity 2 — Guided core task (18 minutes)
**Teacher:** Guide short past-tense recounts with clear event order.
**Pupils:** Write two linked sentences for each event; add a caption.

## Activity 3 — Apply and share (15 minutes)
**Teacher:** Organise sharing; invite questions about an event or feeling.
**Pupils:** Present one memory for one minute; answer a question and revise a caption.

## Reinforcement / PBD (8 minutes)
**Teacher:** Assess three entries, sequencing, past tense and oral reflection.
**Pupils:** Correct one tense/order error; add one clear detail.

## Closure (4 minutes)
**Teacher:** Invite a strong memory sentence and reflection on progress.
**Pupils:** Share a revised past-tense sentence and why it mattered.

## Differentiation and follow-up
Support: picture/word bank, guided modelling and extra processing time. Extension: justify an answer independently or add precise supporting detail.
