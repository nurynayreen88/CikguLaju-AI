# English Year 4 — Lesson 160: Project-Based Learning 2

**Topic:** Teacher-selected topic  
**Main SP:** Teacher-selected DSKP SP  
**Complementary SP:** Teacher-selected DSKP SP  
**Duration:** 60 minutes  
**References:** SOW Lesson 160; teacher selects project; Primary Year 4 SOW Lesson 160

## Set induction (10 minutes)
**Teacher:** Introduce the teacher-selected project theme and outcome.
**Pupils:** Discuss the selected project topic and success criteria.

## Activity 1 (15 minutes)
**Teacher:** Groups plan a project and assign roles.
**Pupils:** Agree on a plan, roles and materials.

## Activity 2 (20 minutes)
**Teacher:** Pupils create and document their project outcome.
**Pupils:** Create the project outcome and document each group's work.

## Reinforcement / PBD (10 minutes)
**Teacher:** Groups present outcomes and receive peer feedback.
**Pupils:** Present the outcome and improve it using peer feedback.

## Closure (5 minutes)
**Teacher:** Reflect on the project process.
**Pupils:** Reflect on group roles and one learning gain.

**PBD:** Assess the specified task against Teacher-selected DSKP SP and Teacher-selected DSKP SP; for teacher-selected standards choose criteria before class.  
**Differentiation:** Provide picture cues, word banks, peer support and optional extensions.
