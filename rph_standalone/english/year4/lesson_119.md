# English Year 4 — Lesson 119: Speaking 23

**Topic:** Amazing animals  
**Main SP:** 2.1.5  
**Complementary SP:** 2.2.2  
**Duration:** 60 minutes  
**References:** SB p.83 Activity 3; TB p.125; dinosaur cards; resources/lesson_119_dinosaur_speaking_clarification_pbd_DRAFT.md; Primary Year 4 SK SOW Lesson 119

## Set induction (10 minutes)
**Teacher:** Review comparative forms using dinosaur pictures.
**Pupils:** Describe dinosaur pictures using comparisons.

## Activity 1 (15 minutes)
**Teacher:** Demonstrate the first Activity 3 animal description and ask pupils to identify the comparative adjective before practising.
**Pupils:** Practise model descriptions from Activity 3.

## Activity 2 (20 minutes)
**Teacher:** Model a clue using a comparative adjective, then organise pair turns in which one pupil describes a dinosaur and the other identifies it from the picture cards.
**Pupils:** Give clues so a partner identifies dinosaurs.

## PBD / reinforcement (10 minutes)
**Teacher:** Assign Workbook p.71, Activity 2 as the main Workbook exercise in Assessment/PBD. Follow its printed instructions and check answers. During the speaking task in Activity 1/2, observe pupils' spoken responses as evidence for the main Speaking SP.
**Pupils:** Complete Workbook p.71, Activity 2; write sentences comparing the two dinosaurs using the adjectives.

## Closure (5 minutes)
**Teacher:** Ask pupils to share a comparative sentence and explain which two dinosaurs it compares.
**Pupils:** Share one comparative sentence.

**PBD:** Observe pupils giving comparative dinosaur clues for main Speaking SP 2.1.5; assess their requests for clarification about partner-task instructions for complementary Speaking SP 2.2.2. Workbook p.71 provides the main written comparative practice, not speaking evidence.  
**Differentiation:** Provide word banks, teacher models, peer support and optional extension.
