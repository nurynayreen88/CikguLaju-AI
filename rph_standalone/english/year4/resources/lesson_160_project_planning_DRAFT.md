# Lesson 160 — Project-based learning planning kit (DRAFT)

SOW Lesson 160 leaves topic, standards and resources to the teacher. This is an **optional** sample.

**Sample project:** English Tips for New Pupils. Groups create a simple welcome guide with three helpful English-learning tips.

**Before class:** Teacher selects actual Year 4 main/complementary SP and measurable criteria. Prepare paper, markers and optional example guide.

**Planning sheet:** Project question: ___. Main SP: ___. Complementary SP: ___. Our audience: ___. Three tips: 1. ___ 2. ___ 3. ___. Roles: ___. Materials: ___.

**Sentence models:** You should ask questions. / You can read a short story. / We should practise speaking because ___.

**Peer review:** Is each tip understandable? Can every group member explain one tip? What will we improve?

**PBD:** Observe planned language outcomes against the teacher's chosen standards, with evidence from the guide and presentation.

**Status:** DRAFT; no fixed SOW project topic is claimed.
