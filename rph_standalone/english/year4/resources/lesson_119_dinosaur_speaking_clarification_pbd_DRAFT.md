# Lesson 119 — Dinosaur speaking and clarification PBD (DRAFT)
Main Speaking SP 2.1.5; complementary Speaking SP 2.2.2.
Use Student's Book p.83 Activity 3, Teacher's Book p.125 and the printed dinosaur cards. This is an original observation sheet, not a substitute for source pictures or dialogue.

## Pair activity response card
Pupil A: __________ Pupil B: __________
1. Look at the approved dinosaur pictures from Student's Book Activity 3.
2. Pupil A describes one pictured dinosaur using a comparative form modelled in the book. Pupil B identifies it.
3. Swap roles. Each pupil gives two different clues about animals actually shown in the approved source.
4. If the instruction is unclear, ask a polite clarification question about what to do, then respond to your partner.
Clue A1: __________ Clue A2: __________
Clue B1: __________ Clue B2: __________
Clarification question used: __________
Partner's helpful explanation: __________
5. Complete Workbook p.71 Activity 2 separately as written comparative practice.

## Individual teacher PBD
Speaking 2.1.5: Makes 0 / 1 / 2 understandable spoken dinosaur comparisons using the approved picture set.
Speaking 2.2.2: Asks for or provides clarification about the task instructions: Independently / With prompt / Not yet.
Record actual spoken evidence, not workbook answers.
Support: Teacher demonstrates using the exact book picture and sentence pattern. Extension: Explain why two pictures differ using another verified comparative adjective.
