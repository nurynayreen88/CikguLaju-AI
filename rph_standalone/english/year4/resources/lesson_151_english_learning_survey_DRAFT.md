# Lesson 151 — English-learning advice survey (DRAFT)

Original non-textbook speaking resource aligned to SOW Lesson 151.

**Pair questions:** What should we do to learn new words? Should we read English stories? How can we practise speaking? What should we do when we do not understand a word?

**Response frames:** “We should ___ because ___.” / “We shouldn't ___ because ___.” / “Could you repeat the question, please?”

**Survey grid:** Partner | One useful learning habit | Reason | Question I asked

**Group report:** “Three pupils think we should ___ because ___.”

**PBD:** Express opinions with reasons (2.1.1) and respond to longer supported questions (1.2.5). Provide paper-based options; no internet or paid learning app is required.
