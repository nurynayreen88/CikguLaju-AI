# English Year 4 — Lesson 137: Writing 26

**Topic:** Get active!  
**Main SP:** 4.2.4  
**Complementary SP:** 3.2.2  
**Duration:** 60 minutes  
**References:** resources/lesson_137_sports_superlative_writing_pbd_DRAFT.md; SB p.97 Activity 2; TB p.143; sports flashcards; Year 4 SOW Lesson 137

## Set induction (10 minutes)
**Teacher:** Review sports vocabulary with flashcards.
**Pupils:** Recall sports words using flashcards.

## Activity 1 (15 minutes)
**Teacher:** Guide pupils to reread the source text and underline two facts useful for a sports description.
**Pupils:** Read and identify details in the source text.

## Activity 2 (20 minutes)
**Teacher:** Model a sports description using a superlative adjective and a supporting fact from the text, then ask pupils to write their own descriptions.
**Pupils:** Write descriptions using superlative adjectives.

## Reinforcement / PBD (10 minutes)
**Teacher:** Assign Workbook p.81, Activity 2 as the main Workbook exercise in Assessment/PBD. Follow its printed instructions and check answers. Assess pupils' own written sentences or text for the main Writing SP; do not rely on isolated vocabulary answers alone.
**Pupils:** Complete Workbook p.81, Activity 2; write a paragraph about a favourite athlete using the information in Activity 1.

## Closure (5 minutes)
**Teacher:** Invite pupils to read a revised sports description and explain one correction.
**Pupils:** Read an improved sentence.

**PBD:** Assess pupils' own sports descriptions using accurate superlatives and relevant details for main Writing SP 4.2.4; check their understanding of supporting information in the printed source text for complementary Reading SP 3.2.2. Workbook p.81 athlete paragraph is the main written practice and should follow its printed instructions.  
**Differentiation:** Provide picture cues, word banks, paired support and extensions where needed.
