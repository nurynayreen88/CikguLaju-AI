# English Year 4 — Lesson 092: Speaking 18

**Topic:** Getting around  
**Main SP:** 2.2.2  
**Complementary SP:** 2.1.3  
**Duration:** 60 minutes  
**References:** SB p.65 Activity 1; TB pp.100–101

## Set induction (10 minutes)
**Teacher:** Review transport model examples.
**Pupils:** Recall examples of transport models.

## Activity 1 (15 minutes)
**Teacher:** Read materials and project instructions.
**Pupils:** Read the materials list and project instructions.

## Activity 2 (20 minutes)
**Teacher:** Check steps with a partner and build a transport model.
**Pupils:** Check steps with a partner and build a model.

## Reinforcement / PBD (10 minutes)
**Teacher:** Present model using First, Second and Next.
**Pupils:** Present the model using First, Second and Next.

## Closure (5 minutes)
**Teacher:** Review action verbs.
**Pupils:** Recall action verbs used in the task.

**PBD:** Assess task responses against 2.2.2 and 2.1.3; teacher selects specific criteria for Language Awareness.  
**Differentiation:** Provide word banks, examples, partner support and extension tasks as needed.
